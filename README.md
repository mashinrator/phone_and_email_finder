# Phone and Email Finder
This program is used to find phone and email from the clipboard copied text, then copy everything that the program found.
## How to download
1. Download the ZIP file by clicking "Code <>" button;
2. Unzip the file to the folder.
3. ## How to use
1. Copy the text (you can use a text from the website for example;
2. Launch start.bat;
3. Paste the new copied text to check the result.
